# Bike Store Sale Dashboard
# Project Overview
This project involves creating a dashboard for the sales at a bike store, the goal is to provide a user friendly dashboard that for the users to interact with the data and showcase the bike sales based on different demographics.

# Dataset
The dataset used for the dashboard is obtained by https://www.kaggle.com/datasets/prepinstaprime/europe-bike-store-sales/data
# Keysteps in the project
- Data cleaning on the dataset,removing duplicates and errors, additional categories(identifying the season of the sale based on the month)
- Creating pivot table, using pivot table to analyze the data
- Creating Charts, Using the pivot table to create charts that displays information, and using slicers for the user to toggle the data
- Dashboard Creation, putting the charts together for a dashbaord that displays the information
# Instruction for use
download the excel file of the Bike Store Sale Dashboard.xlsx 
explore the interactive dashboard to gain insight on the sales of the bike store
